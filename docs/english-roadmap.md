# 英语学习路线

## 阶段一：夯实基础（大一）

目标：建立稳定词汇量、掌握基础语法，形成阅读习惯。

### 词汇

- 每日 15—20 个目标词
- 当天复习一次，隔日复习一次
- 按“单词—例句—近义辨析”记录
- 优先选择专升本通用高频词

### 语法

1. 名词与冠词
2. 动词时态
3. 被动语态
4. 从句：名词性、定语、状语
5. 非谓语动词
6. 虚拟语气与主谓一致

### 阅读

- 每周 3 篇短文
- 先读后查生词，第二遍分析句子结构
- 总结主旨、长难句与出题规律

## 阶段二：考点强化（大二）

- 词汇量扩充至专升本考试要求
- 完成真题词汇与语法专项
- 阅读文章进行限时训练
- 开始积累完形填空和翻译常见句型
- 每周一次听写或模拟

## 阶段三：冲刺（大三）

- 按考试科目和题型安排套卷
- 真题至少反复做两轮
- 建立错题词、错题语法和阅读失分清单
- 最后阶段压缩到高频考点和薄弱题型

## 当前一周任务

- 每天背 15 个单词并复习旧词
- 完成基础时态与被动语态笔记
- 阅读 2 篇短文，分析 3 个长难句
- 错题复盘一次
